Brazilian Portuguese spelling dictionary (VERO)

NEO distributes the dictionary and affix data from dictionary-pt 4.0.0,
which is VERO, the Brazilian Portuguese Hunspell dictionary used by
LibreOffice, under the Mozilla Public License 2.0 option of its
LGPL-3.0 / MPL license. NEO's MIT license does not replace the
dictionary's license, and NEO does not remove the LGPL alternative.

Original dictionary: VERO — Verificador Ortográfico do LibreOffice.

The full upstream attribution and license notice is in upstream-license.txt.
The full selected license is in MPL-2.0.txt.

Source availability

The dictionary source files index.aff and index.dic are included verbatim,
unmodified, with every packaged app, together with the upstream license, in
the same directory as this notice:
  app.asar.unpacked/node_modules/dictionary-pt/

On macOS this is inside NEO.app/Contents/Resources. On Windows and Linux
it is inside the application's resources directory. An AppImage can be
extracted using --appimage-extract.

The same files are available from the pinned source package:
https://registry.npmjs.org/dictionary-pt/-/dictionary-pt-4.0.0.tgz
Package project: https://github.com/wooorm/dictionaries/tree/main/dictionaries/pt
Dictionary project: https://pt-br.libreoffice.org/projetos/projeto-vero-verificador-ortografico/
