Hunspell spellchecking engine

NEO checks spelling with Hunspell 1.7.3, compiled to WebAssembly and
distributed inside the npm package @farscrl/hunspell-wasm 1.0.1 (its
JavaScript wrapper is MIT-licensed; see its LICENSE file in app.asar under
node_modules/@farscrl/hunspell-wasm).

NEO does not modify Hunspell. The exact source compiled into the package
