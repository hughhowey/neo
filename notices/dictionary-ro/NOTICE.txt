Source availability

The dictionary source files index.aff and index.dic are included verbatim
with every packaged app, together with the upstream license, in the same
directory as this notice:
  app.asar.unpacked/node_modules/dictionary-ro/

On macOS this is inside NEO.app/Contents/Resources. On Windows and Linux
it is inside the application's resources directory. An AppImage can be
extracted using --appimage-extract.

The same files are available from the pinned source package:
https://registry.npmjs.org/dictionary-ro/-/dictionary-ro-3.0.0.tgz
Package project: https://github.com/wooorm/dictionaries/tree/main/dictionaries/ro
Dictionary project: https://rospell.wordpress.com/

Lookup, updated 2026-09-30

Since NEO 1.2, Hunspell reads index.aff and index.dic exactly as
distributed; no conversion is applied. Lookup normalizes Romanian
diacritics (spell-ro.js, in app.asar and in NEO's source repository,
https://github.com/hughhowey/neo) without altering manuscript text.
